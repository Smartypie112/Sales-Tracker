DM Tracker

A simple personal CRM and sales tracking dashboard built for managing Instagram cold outreach and client acquisition.

Features

📊 Dashboard Metrics

Track your complete outreach funnel:

- Cold DMs Sent
- Replies Received
- Interested Leads
- Clients Closed

📈 Conversion Analytics

Automatically calculates:

- Reply Rate
- Interest Rate
- Close Rate
- Overall Conversion Rate

🔥 Interested Leads Management

Store and manage potential clients with:

- Instagram Username
- Name
- Niche
- Notes
- Last Contact Date

💰 Client Management

Track active clients including:

- Client Name
- Instagram Username
- Price Per Reel
- Reels Per Month
- Monthly Revenue

💵 Revenue Tracking

Automatically calculates total monthly revenue from all active clients.

💾 Local Storage Support

All data is stored in the browser using Local Storage, so information persists between sessions without requiring a backend.

---

Tech Stack

- HTML5
- Tailwind CSS
- Vanilla JavaScript
- Local Storage

---

Purpose

I built this project to track my Instagram outreach process as a video editor.

The goal is to monitor:

1. How many cold DMs I send.
2. How many people reply.
3. How many become interested.
4. How many convert into paying clients.

This helps me measure conversion rates and understand which outreach strategies are producing results.
